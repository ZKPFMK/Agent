# 类别 C：多智能体协作攻击 taxonomy

## 证据范围

本 taxonomy 依据 C01–C19 摘要 Markdown。C12 是故障韧性与防御评测，应作为反事实基线而不是直接攻击证据。C 类按攻击是否利用协作关系、消息传播、角色组合或多 Agent 汇聚来界定；外部内容和内部记忆只在它们通过协作机制形成失败时纳入。

## 分类轴

主轴是**协作结构被改变的部位**：通信信道、传播/感染、恶意节点/勾结、路由/工具/编排、资源与协作可用性。第二轴是**系统后果**：错误输出、信息泄露、信念操纵、代码/工具后果、协作瘫痪。

### C1. 通信信道和消息篡改

- 代表论文：C03 Secret Collusion、C05 AiTM、C06 Agents Under Siege、C13 MAST、C16 Conjunctive Prompt Attacks。
- 入口：消息拦截、隐写、提示分段、跨 Agent 路由或多轮消息。
- 机制：把单个消息的表面语义和真实协作作用分开，利用拓扑、带宽、延迟或组合触发绕过单点检测。
- 主要指标：ASR、隐蔽性、误激活率、跨拓扑迁移。
- 限制：消息干预权限在真实系统中不统一；每篇论文的攻击预算和可见通信范围不同。

### C2. 感染、复制和知识传播

- 代表论文：C04 Security Tax、C07 ARCJ、C11 Prompt Infection、C19 Manipulated Knowledge Flooding；B02 是直接相邻工作。
- 入口：一个被攻破 Agent、独立记忆、聊天历史、RAG 或多跳通信。
- 机制：恶意提示、知识或记忆通过协作传播，造成毒性衰减、复制、存储和再次检索。
- 主要指标：传播率、感染时间/跳数、目标偏移、知识持久性、安全税、协作性能。
- 限制：大规模/非完全图多是模拟；传播与正常知识共享的因果区别、清理后恢复和长期持久性未统一评估。

### C3. 恶意 Agent、秘密勾结和信念操纵

- 代表论文：C01 Evil Geniuses、C02 PsySafe、C03 Secret Collusion、C09 Who’s the Mole、C18 Lying with Truths。
- 入口：角色定义、恶意节点、隐写信道或公开真实证据组合。
- 机制：恶意意图隐藏、角色心理特质、秘密通信或真实片段的叙事编排，使监督者/受害 Agent 不能从单条消息判断真实目的。
- 主要指标：危险行为率、隐藏成功率、信念/因果错误率、下游欺骗率、检测率。
- 限制：C02 的心理相关性不能直接证明攻击因果；C18 的局部真实和全局错误在合成信息环境中成立，现实外推需要额外验证。

### C4. 路由、工具和编排链攻击

- 代表论文：C08 MASLEAK、C10 任意恶意代码、C14 IMBIA、C17 Evo-Attacker。
- 入口：公开 API 查询、网页/文件内容、代码开发需求、工具输出和长期工具链。
- 机制：利用编排器、任务分解、工具调用或 Agent 间响应拼接，得到单个 Agent 防御也难阻止的系统后果。
- 主要指标：架构/提示泄露率、代码注入成功率、工具攻击成功率、任务完成率。
- 限制：后果严重的论文通常依赖特定编排器和工具；授权实验必须使用无害哨兵工具和假秘密。

### C5. 协作拒绝与资源耗尽

- 代表论文：C15 CORBA；A13、B08 提供相邻资源/故障机制。
- 入口：语义上良性的递归指令、消息循环或重复操作。
- 机制：把通信拓扑变成自我放大结构，使系统陷入无意义协作而非单节点服务拒绝。
- 主要指标：消息数、循环深度、token/时间预算、任务成功率、恢复时间。
- 限制：必须有硬性步数和资源上限；本项目只在离线沙盒模拟，不接触真实服务或制造外部负载。

## 防御和反事实

C11 提出 LLM Tagging，C04 评估疫苗记忆和通用安全指令，C09 以 AgentXposed 检测隐藏意图，C12 以 Challenger/Inspector 测韧性，C14 提出 Adv-IMBIA，C19 采用批判提示和监督 Agent。C03 报告监控、释义和参数优化局限；C05/C06/C13/C16 均提示单 Agent 或单消息检测不足。

摘要层面的共同限制是：防御通常针对一个阶段，缺少“外部输入—记忆—规划—协作传播—工具后果”的全链路因果测量；单组件安全也不能推出组合安全。该判断是本项目综合推断，需在正文与后续实验中验证。
