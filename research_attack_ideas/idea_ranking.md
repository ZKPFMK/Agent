## 排序理由

### 1. I1：真实片段的记忆持久化级联

它同时有 C18 的机制证据、B10/B13 的低权限记忆证据和 C19 的传播/持久化证据，能用合成因果图把“每条证据为真”和“整体因果错误”分开测量。失败判据直接，且只需离线 Agent、记忆模块和 canary 工具。新颖性主要来自跨阶段因果测量，仍需诚实标记为组合型假设。

### 2. I2：外部间接输入到内部状态再到协作

它把 A 类最成熟的外部入口与 B/C 类的状态和传播后果连接起来，能够回答“即时响应正常是否掩盖未来偏移”。可行性高于 I1 的真实信息环境版本，但受自动记忆实现影响更大，安全边界也更依赖模拟器，因此略低于 I1。

### 3. I3：工具偏好迁移

A10/A11/A19 已经覆盖工具投毒和偏好操纵；I3 的贡献是持久性、跨任务和跨 Agent 指标，属于明确的增量扩展。工具沙盒容易构建，适合在 I1/I2 后作为补充实验。

### 4. I4：记忆放大与协作拒绝

C15 已直接提出 CORBA，A13/B08 也覆盖成本/故障放大；新增的记忆因素尚未证实，且资源实验容易把实现限制误判为攻击。只有在严格步数和成本上限下才适合探索，不推荐作为首个方向。

## 研究决策

- 立即验证：I1、I2。两者先分别做单 Agent 记忆对照，再做少量多 Agent 传播；不要一开始把所有阶段同时打开。
- 后续备选：I3。只有当 I1/I2 显示持久状态存在可重复差异时，再测试工具偏好迁移。
- 暂缓：I4。先复核 C15 正文、资源指标和停止条件；否则它可能只是已有 CORBA 的记忆化版本。

## 已排除的表面想法

- 只把 A14、B13 或 C13 换一个模型、数据集或提示词：属于增量复现，不能作为独立研究空白。
- 只增加 Agent 数量而不测量传播阈值、记忆状态或拓扑反事实：不能证明多 Agent 机制。
- 直接把多篇攻击串联并宣称“全链路攻击”：若没有中间状态日志和逐阶段消融，只是演示，不足以支持机制结论。
