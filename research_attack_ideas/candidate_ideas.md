# 候选攻击研究想法

## 证据使用规则

每个想法都区分：

- **文献事实**：来自 `paper_inventory.md` 中有摘要证据的论文 ID。
- **合理推断**：把已有机制连接起来的研究设计判断。
- **未经验证假设**：必须通过下述最小实验否证；不能当作攻击已有效。

所有实验限定在授权、离线、合成数据和无害 canary 工具中，不访问真实用户、凭证、第三方服务或生产系统。

## I1：真实片段的记忆持久化级联

**核心假设（未经验证）：**

> 在攻击者控制一组逐条事实正确但组合后暗示错误因果关系的合成证据片段、且 Agent 会自动总结并保存外部信息的威胁模型下，如果片段的顺序与多 Agent 汇聚使错误因果关系进入长期记忆，系统会因为“局部真实检查不等于全局因果正确”而在未来规划中重复错误信念，并且相较于无记忆单 Agent 基线，在错误因果信念率、记忆污染率和下游 Agent 复述率上产生可测量差异。

**直接参考论文和证据：**

- C18：生成式蒙太奇以局部真实片段和排序诱导全局错误信念；摘要报告 14 个 LLM 系列易受影响，并观察到下游欺骗超过 60%。
- B13：多条看似良性的查询协作改变长期记忆，且比单记录更有效、更难过滤。
- B10：仅查询交互即可通过桥接步骤影响未来记忆。
- C19：操纵知识能在多 Agent 通信中传播并通过 RAG 记忆持久化。

**与已有工作的区别：**

- 它不是单独复现 C18 的公开信道信念操纵，也不是单独复现 B10/B13 的恶意记忆注入。
- 新增的研究对象是**事实片段的全局因果误读是否被自动记忆系统保存，并在多 Agent 中被当成独立证据再次传播**。
- 新颖性主要属于机制组合后的跨阶段因果测量和评价设置；不是已被证明的新通用攻击。初步标记为“组合型、机制有区分度，但需先做空白核对”。

**威胁模型：**

- 攻击者控制授权沙盒中的合成证据片段及其发布顺序；每条片段都能由测试 oracle 验证为事实正确。
- 攻击者不知道模型权重和内部记忆实现，不能修改权重、系统提示或真实文件。
- 攻击者能观察 Agent 的公开输出，最多控制一个或少数发布节点；不接触真实网络。
- 系统含一个自动摘要/记忆模块和 2–4 个协作 Agent；不需要工具权限，工具只保留无害 canary。

**攻击机制（授权沙盒）：**

1. 生成带已知真实因果图的合成事件和若干无因果关系的事实片段。
2. 由受控发布者按不同顺序提供片段；比较随机顺序与叙事优化顺序。
3. 让受害 Agent 输出摘要并按系统正常规则写入长期记忆；不直接写数据库。
4. 在隔离的后续任务中检索记忆，观察规划是否添加真实图中不存在的因果边。
5. 让下游 Agent 只接收上游摘要，测量错误信念是否继续传播。

**最小可行实验（1–3 天）：**

- 最小系统：一个受害 Agent、一个记忆模块、两个下游 Agent、一个只记录调用的 canary 工具。
- 数据：30–50 个合成事件图，每个图 6–10 个片段；攻击者只能选序和片段集合。
- 组别：无攻击随机序列；有序片段但不写记忆；有序片段自动写记忆；有序片段写记忆后经过两个 Agent 汇聚。
- 主要变量：只改变“是否记忆持久化”和“是否跨 Agent 汇聚”，模型、任务提示、片段内容和预算固定。
- 指标：局部事实正确率、错误因果信念率、记忆污染率、下游复述率、置信度、记忆清理后的残留率。
- 预期结果（假设）：若持久化和汇聚是关键，后两组的错误信念/复述率应高于相同片段的无记忆或随机顺序组；不能预先填写数值。

**失败条件：**

- 受害 Agent 在有序片段中也不产生高于随机序列的错误因果信念。
- 错误信念出现但从未被记忆保存，或只在单次即时回答出现。
- 下游传播率不超过无攻击/随机摘要的置信区间。
- 结果只在一个模型、一个图结构或某一片段措辞上出现，且顺序/内容置换后消失。

**防御与反事实：**

- 反事实：随机置换片段、显式给出因果独立性、关闭自动记忆、只保存带 provenance 的原子事实。
- 防御：记忆写入前的因果一致性检查；记忆条目标注来源并禁止把 Agent 生成的因果总结当作独立证据；下游要求引用原始片段。
- 只有在防御前后差异稳定、且局部真实约束始终满足时，才可讨论机制性。

## I2：外部间接输入到内部状态再到协作的状态级联

**核心假设（未经验证）：**

> 在攻击者只能控制授权网页/搜索模拟器中的一条外部内容、不能修改模型或直接写记忆的威胁模型下，如果系统会把外部内容自动摘要到长期状态并在后续任务中共享，系统会因为外部内容的指令/状态混淆而产生“即时行为正常、未来规划偏移”的级联，并且相较于无记忆单 Agent 基线，在记忆写入率、后续 canary 动作率和跨 Agent 传播率上产生可测量差异。

**参考论文：**

- A02/A04/A14：网页/上下文间接注入，分别提供黑盒、自动优化和仿聊天模板/多轮条件下的外部入口证据。
- B10/B12：外部查询或图像可成为低权限记忆改变的入口。
- C11/C16：消息感染或跨 Agent 组合可使单组件看似正常的输入产生系统级后果。
- C10：摘要报告外部内容能经过编排和通信流造成比单 Agent 更严重的结果，但未给出持久状态的分解。

**与已有工作的区别：**

- 它不是把 A14 换一个模型或网页，也不是把 C11 的传播次数扩大。
- 新增因素是把“外部注入成功”与“记忆写入、未来任务偏移、消息传播”分成可观测中间变量，并做单因素消融。
- 新颖性属于跨阶段评估/威胁模型，机制本身可能是已有攻击的组合，因此标记为“增量组合想法”。

**威胁模型：**

- 控制一个离线网页/搜索文档的内容；只观察 Agent 输出。
- 不知道权重，不修改系统提示、工具实现或数据库；只利用系统既有的自动摘要机制。
- 不需要真实工具权限；canary 工具只返回固定字符串并记录是否被调用。
- 需要 1 个受害 Agent 和 2 个下游 Agent，交互轮数固定。

**最小可行实验：**

- 任务：合成知识检索和计划任务，外部文档可包含正常信息或经模板化的状态诱导文本。
- 组别：无外部文档；外部文档但禁用记忆；外部文档自动记忆；外部文档自动记忆并共享给下游 Agent。
- 变量控制：每个区块只改变一个因素；文档长度、任务目标、模型、调用预算固定。
- 指标：即时注入成功率、记忆写入/检索率、后续任务偏移率、canary 调用率、跨 Agent 传播率、正常任务成功率和检测率。
- 预期结果：若级联成立，记忆和共享组的后续偏移高于无记忆组，而即时任务成功率可能暂时不变。

**失败条件：**

- 外部文档只影响当前回答而不进入记忆，或记忆进入但不改变后续规划。
- 共享后续 Agent 的偏移不高于单 Agent 组。
- 防御/反事实组同样产生偏移，说明指标或任务设计有问题。
- 只在一个模板或一个 Agent 实现上成功；更换文档顺序、模型或任务后消失。

**防御与反事实：**

- 自动记忆禁用、摘要仅保留可验证原子事实、外部内容和系统指令分层隔离、消息 provenance 标签、canary 调用前人工式策略检查。
- 对比同一内容从网页、工具描述和 Agent 消息三个入口进入时的结果；该对比只用于定位入口效应，不将其当作新的攻击能力。

## I3：工具元数据偏好向长期路由的迁移

**核心假设（未经验证）：**

> 在攻击者只能控制授权沙盒中一个候选工具的名称/描述、不能执行工具或修改模型的威胁模型下，如果 Agent 会把选择结果或工具评价写入共享状态，元数据偏好会因为工具选择与记忆检索的耦合而持续影响后续任务和其他 Agent，并且相较于一次性工具选择基线，在选择偏移持久性和跨 Agent 转移率上产生差异。

**参考论文：**A10、A11、A19 证明工具投毒/偏好/选择入口；B13 证明看似良性记录可持续改变记忆；B14/C17 提供跨工具和长期工具链的相邻证据。

**区别和级别：**

- A10/A11/A19 已覆盖即时工具元数据攻击；I3 新增的是持久偏好和跨 Agent 路由测量。
- 主要是威胁模型与评价指标扩展，标记为“增量想法”。

**最小实验与安全边界：**

- 三个离线无副作用工具，只有一个返回固定 canary；两个 Agent；20–30 个合成任务。
- 比较一次选择、重复选择、共享偏好和清空偏好；记录选择率、跨任务持久性、跨 Agent 转移率、正常任务成功率。
- 不执行网络、文件写入、外发、凭证读取或真实 MCP 服务器；工具调用只写本地日志。

**失败条件和反事实：**

- 元数据只影响当前选择，清空状态后不再出现；或共享状态没有跨 Agent 影响。
- 工具 allowlist/描述隔离完全消除效果，说明问题可由已知边界解决；这仍是有价值的防御结果，但不支持更强机制主张。

## I4：语义良性递归指令的记忆放大与协作拒绝

**核心假设（未经验证）：**

> 在有限步数的离线多 Agent 图中，如果一个语义上良性的递归协作指令被自动记忆并再次检索，系统会因为消息循环和记忆回放形成资源放大，并且相较于不持久化记忆的协作基线，在消息数、token 预算和任务完成时间上产生差异。

**参考论文：**C15 CORBA 提供协作拒绝机制；A13 提供计算成本攻击；B08 提供故障放大；C13 提供多轮隐蔽消息干预。

**区别和级别：**

- 新增“记忆持久化是否把一次性协作循环变成跨任务循环”的因果问题。
- 机制组合接近已有工作，且 C15 已直接研究递归阻塞，因此标记为“增量/低优先级”。

**最小实验与安全边界：**

- 3 个 Agent、两种小拓扑、最大 20 个协作轮次、每轮严格 token/时间上限；消息只在内存模拟队列中流转。
- 比较无记忆、短 TTL、持久记忆；指标为消息数、循环深度、token、任务成功率、停止器误报率。
- 禁止真实网络、并发压力、服务调用和无限循环；到达预算立即终止。

**失败条件和反事实：**

- 记忆清空与否不改变循环；或停止器/拓扑控制已完全阻断，说明 I4 的新增因素不成立。
- 资源差异只来自实现 bug、token 上限或不同提示长度时，不能称为机制性攻击。
