# 三类 AI Agent 攻击论文统一证据清单

## 证据边界

本清单覆盖目标目录中的 54 个论文子目录和 54 个 PDF。ID 按各目录子目录名字典序分配：A01–A21 为外部交互，B01–B14 为内部认知，C01–C19 为多智能体协作。完整的机器可读字段见 [paper_matrix.csv](./paper_matrix.csv)。

本轮环境没有 `pdftoppm` 或其他可用的系统 PDF 渲染器，专用 PDF 读取也无法运行；因此下列记录以同目录中文摘要 Markdown 为主要证据，C18 另有摘要中的引言与第 3 节摘录。除明确写出“正文章节”外，页码、作者、附录实验细节均为“未验证”。摘要中出现的代码或数据链接只记录为来源线索，不代表代码已在本地存在或已复现。

证据等级：

- **摘要核对**：字段来自同目录摘要 Markdown 的标题、摘要或其明确列出的数字。
- **摘要扩展**：来自摘要 Markdown 中额外保留的引言/章节内容（当前主要是 C18）。
- **推断**：依据已核对机制对分类边界或跨类别关系作出的分析，不能当作论文作者的结论。
- **未验证**：摘要缺失、PDF 无法读取或摘要没有报告该字段。

作者字段在 52 个摘要 Markdown 中均未出现可核对的作者列表，因此统一记为：**未验证：摘要未给作者，PDF 正文未逐页核对**。目录年份只作为线索；A07、A10、A21 的年份字段尤其不能从目录前缀直接升级为事实。

## 目录与实际类别的初步冲突

- B02、C04、C07、C11、C19 同时涉及记忆、提示或知识传播；按主要系统对象分别归入 B 或 C，交叉关系是分析结论而非论文原分类。
- B14、A10、A19、C17 都涉及工具元数据/工具输出/工具选择；它们分别强调内部控制流、外部工具生态或多 Agent 长期协作，不能仅按“工具攻击”合并。
- C10、C14 以多 Agent 为主，但入口分别是外部恶意内容和软件开发流程；归入 C 的依据是失败是否经过编排/通信传播。
- C12 主要是故障韧性和防御评测，不能把它的 AUTOINJECT 直接称为攻击成功证据；本清单将其作为 C 类反事实基线。
- A07、A21 的分类只来自目录位置，实际标题、作者、年份、机制、指标和冲突均未验证。

## 资料缺口

1. 缺少 54 篇 PDF 的逐页文本核验，导致作者、页码、附录、具体表格和多数基线数值未确认。

3. 目标目录没有本地代码、日志或复现实验输出；外部 URL 只作为论文记录中的来源线索。
4. 许多摘要把“高 ASR”“显著提升”作为结论，但未提供分母、置信区间、重复次数或统计检验；本项目不会把这些表述升级为普遍性结论。
