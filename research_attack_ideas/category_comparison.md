# A/B/C 类别比较

## 统一比较表

| 维度 | A 外部交互 | B 内部认知 | C 多智能体协作 |
|---|---|---|---|
| 主要对象 | 网页、搜索结果、视觉界面、工具元数据、外部证据 | 模型后门、长期记忆/RAG、推理规划、知识文件、控制流 | 消息信道、拓扑、角色/恶意节点、编排、协作资源 |
| 常见攻击者能力 | 控制或影响 Agent 可见外部内容；多为黑盒 | 从供应链训练权限到仅查询交互；能力跨度最大 | 控制一个 Agent、部分消息、工具输出或角色；通常依赖多 Agent 连接 |
| 发生阶段 | 感知、检索/选择、规划、动作 | 写入/检索记忆、推理、任务分解、工具控制流、数据泄露 | 消息生成/路由、跨跳传播、协作汇聚、工具编排、资源循环 |
| 典型目标 | 外泄、工具误用、错误事实、任务偏移、成本增加 | 后门行为、记忆污染、隐私泄露、目标/规划偏移 | 错误传播、秘密勾结、系统泄露、代码/工具后果、协作瘫痪 |
| 常见指标 | ASR、点击/受影响率、外泄率、任务成功率、成本 | ASR/GHR、投毒率、良性性能、检测率、提取率、任务失败率 | 传播率、跳数、隐蔽性、信念错误率、拓扑鲁棒性、资源/恢复指标 |
| 常见防御 | 提示隔离、内容检测、困惑度/语义检测、工具约束、人工监督 | 可信微调、记忆清理、反事实验证、审计、权限限制 | 消息监控、标签、疫苗/安全指令、监督 Agent、挑战者/检查者、拓扑控制 |
| 共同限制 | 多为单 Agent 或短流程；指标不统一 | 记忆实现和内部接口差异大；真实低权限条件不统一 | 拓扑、通信可见性、攻击预算差异大；故障不等于恶意攻击 |

## 重要相同点

1. 三类都利用“内容的语义作用”超过了其表面标签：A16 说明角色表达可覆盖标签，B13 使看似良性查询协作改变记忆，C16 使单独良性的触发器和模板在路由后共同激活。[文献事实 + 综合推断]
2. 三类都显示单点提示防御难以覆盖跨阶段行为：A14/A19 的载荷可适配模板或工具选择，B10/B12 让影响延迟到未来记忆检索，C11/C13/C18 让影响跨 Agent 传播或由多个输出汇聚。[文献事实]
3. 许多摘要报告高 ASR或显著影响，但不同论文的分母、预算、任务、模型和统计方法不同，不能把这些数字排成一个总榜。[方法学结论]

## 关键不同点

- A 的攻击者通常控制输入内容，较少拥有内部写权限；B 的关键问题是内容如何进入/改变内部状态，即使入口是外部查询；C 的新增条件是多个 Agent 之间存在传播、路由或汇聚，单 Agent 失败不是充分条件。
- A 主要测试“当前动作是否偏移”，B 主要测试“未来检索/规划是否偏移”，C 主要测试“一个节点的状态或消息是否改变整体协作”。
- A 和 B 的防御可分别隔离输入或清理记忆，但 C 需要证明隔离后的消息在路由和多跳传播下仍然安全；C12 的韧性结果说明拓扑本身也会改变故障后果。

## 研究对象交叉关系

- A × B：A02/A05/A14 的外部内容可以作为 B10/B12/B13 的潜在记忆写入入口；B04 明确把环境观测作为后门触发位置。现有摘要没有统一因果链验证。
- A × C：A10/A19 的工具元数据和 A02/A04 的外部内容都可能经过编排器或消息路由进入 C10/C13/C16 的协作过程；C10 报告单 Agent 防御不足，但没有把外部输入、内部状态和拓扑因素拆开。
- B × C：B02/B10/B13 的记忆/传播机制与 C04/C07/C11/C19 相近；关键差异是记忆写入是否自动发生、传播是否依赖消息、以及污染是否持久。摘要没有统一比较。
- A × B × C：C18 已展示外部真实证据、受害 Agent 信念和下游传播的链式组合，但其目标是信念操纵；尚未在同一小型沙盒中把“外部内容→持久记忆→规划改变→多 Agent 传播→受控工具后果”作为可分解的因果链来比较。[探索性推断]

## 解释性原则

将论文按类别放置是为了建立基线，不意味着类别互斥。对于研究空白，只有当每个阶段都有独立对照、反事实和失败判据时，组合才构成机制问题；把同一提示换模型、换数据集或把多个已有攻击串联而不测量中间状态，均只算增量组合。
