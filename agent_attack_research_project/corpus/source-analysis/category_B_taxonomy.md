# 类别 B：内部认知攻击 taxonomy

## 证据范围

本 taxonomy 依据 B01–B14 摘要 Markdown。B 类论文的“内部”并不总意味着攻击者直接读取隐状态；有些攻击从用户查询、环境反馈或图像开始，但失败在记忆、规划、推理、权限和控制流中。下列机制事实来自摘要；阶段边界和交叉归纳属于本项目推断。

## 分类轴

主轴是**被改变或利用的内部状态**：模型/任务后门、长期记忆/RAG、隐私数据流、推理规划/控制流。第二轴是**攻击者能力**：供应链/训练权限、可写知识库、仅查询交互、运行时环境输入。

### B1. 模型或任务后门

- 代表论文：B01 BadAgent、B04 Watch Out for Your Agents、B07 DemonAgent。
- 入口：后门数据微调、用户查询或环境观测中的触发器。
- 机制：触发器让 Agent 执行恶意最终输出或中间行为；B07 进一步将后门加密并拆分以降低审计可见性。
- 主要指标：ASR、良性性能、检测率。
- 共同限制：攻击者需要模型/任务数据供应链能力；摘要没有统一比较触发器跨任务迁移和审计器覆盖范围。

### B2. 长期记忆或 RAG 投毒

- 代表论文：B03 AgentPoison、B10 MINJA、B12 Visual Inception、B13 MemIncept。
- 入口：直接写入知识库、仅查询导致系统自动写记忆、图像上传、看似良性的协作查询。
- 机制：让恶意记录具有高检索概率并在未来规划中改变行为；B10/B13 强调低权限和隐蔽性，B12 强调多模态休眠记忆。
- 主要指标：ASR/GHR、良性性能变化、投毒率、持久性、检测率、延迟。
- 共同限制：记忆写入策略、检索模型、TTL/清理机制差异很大；摘要没有把同一任务下“无记忆—单记录—协作记录”统一分解。

### B3. 记忆与知识文件隐私泄露

- 代表论文：B05 MEXTRA、B06 GPT 知识文件泄露。
- 入口：黑盒查询、元数据、检索、沙箱和工具权限。
- 机制：从内部记忆/知识文件及数据流中逐步提取敏感内容，Code Interpreter 可能扩大权限。
- 主要指标：提取成功率、字段/文件完整性、泄露比例。
- 共同限制：真实平台数据流和用户隐私样本复杂；本项目只在合成秘密和无害 canary 上做实验。

### B4. 推理、规划与控制流劫持

- 代表论文：B08 Breaking Agents、B09 UDora、B11 JailAgent、B14 XTHP。
- 入口：重复/无关操作诱导、内部推理轨迹扰动、记忆检索、工具组合和跨工具依赖。
- 机制：将局部错误或受控扰动放大为错误规划、错误工具调用或控制流偏移。
- 主要指标：任务失败率、目标动作率、控制流劫持率、工具误用率、检测率。
- 共同限制：B09/JailAgent 对内部轨迹可见性或可优化信号的要求需要正文确认；B08 的“故障”与策略性攻击不能混为一谈；B14 的 75% 是被报告易受影响的工具比例，不等于所有工具都可被实际攻击。

## 内部攻击与外部/协作边界

- B04 明确允许环境观测触发后门，说明“外部交互”和“内部状态”按阶段划分会产生重叠。
- B10/B13 只需查询即可改变记忆，削弱了“攻击者必须直接写入内部状态”的传统假设。
- B02 的传播机制与 C04/C07/C11 相近；区别在于 B02 的摘要把初始突破和多模态记忆感染作为核心，而 C 类更强调通信拓扑和协作传播。
- B14 的工具控制流与 A10/A19 的元数据操纵相交；分类依据应是攻击首先改变工具生态还是 Agent 内部控制流。

## 共同防御和未覆盖设置

摘要中出现的防御包括可信微调、文本后门防御、自我检查、COGNITIVEGUARD 的感知净化与反事实验证、审计、输入/输出过滤和工具权限限制。现有摘要多在单一阶段报告效果，尚未形成共同指标来判断外部注入是否成功写入记忆、是否改变后续规划、是否再传播到其他 Agent。

本 corpus 的空白候选是：外部真实内容或工具元数据在无显式恶意后门的情况下写入记忆，随后改变多 Agent 规划；以及记忆污染对不同通信拓扑和审计方式的交互作用。两者需通过后续正文核对和小规模实验验证。
