# 类别 A：外部交互攻击 taxonomy

## 证据范围

本 taxonomy 依据 A01–A20 的中文摘要 Markdown；A07、A21 无摘要且不进入机制结论。摘要中的数字是文献事实；对统一攻击面和阶段的归纳是本项目推断。PDF 正文、附录和本地代码未逐页核对。

## 分类轴

主轴是**攻击者首先控制的外部对象**，因为同一个提示词在网页、视觉界面、工具元数据和搜索结果中的信任边界不同。第二轴是**Agent 发生偏移的阶段**：感知/解析、检索/选择、规划/推理、动作/资源后果。

### A1. 网页与文本内容注入

- 代表论文：A02 WIPI、A04 AgentVigil、A05 EIA、A06 AdvAgent、A09 Fact2Fiction、A13 CostBomb、A14 ChatInject、A17 SafeSearch、A18 ObliInjection。
- 攻击者入口：网页正文、搜索结果、事实证据、跨轮上下文或多源片段。
- 共同机制：Agent 把外部内容当作任务相关指令、证据或推理上下文，攻击者利用黑盒反馈、优化、排序不确定性或聊天模板提高成功率。
- 主要失败：工具误用、隐私泄露、事实核查错误、计算预算增加、错误信息输出。
- 证据差异：A02/A05 给出黑盒网页 ASR；A04/A06/A14/A18 强调自动优化和迁移；A09/A17 更接近评测或证据污染。它们的 ASR 分母、任务和攻击预算不能直接合并。
- 共同限制：多数是单 Agent、单轮或短流程；长期记忆写入和跨 Agent 后果在摘要中未被系统比较。

### A2. 视觉与界面操纵

- 代表论文：A03 弹窗、A08 MIP、A12 WebDecept、A15 VPI-Bench、A20 暗黑模式。
- 攻击者入口：屏幕截图、弹窗、网页视觉布局、HTML/视觉属性、壁纸或页面上的图像区域。
- 共同机制：模型的视觉显著性、布局理解或界面语义被人类可忽略的内容改变。
- 主要失败：点击错误目标、购物决策偏移、未授权动作、任务失败和隐私风险。
- 证据差异：A03 报告点击与任务成功率，A15 报告 CUA/BUA 平台 ASR，A20 报告暗黑模式平均影响；指标分别衡量点击、被欺骗和受影响概率，不能视为同一 ASR。
- 共同限制：真实人类交互与模型视觉交互差异未完全隔离；界面组合和长期记忆后果较少涉及。

### A3. 工具元数据与工具选择操纵

- 代表论文：A10 MCPTox、A11 MPMA、A19 ToolHijacker；与 B14 的跨工具控制流相交。
- 攻击者入口：MCP 工具名称、描述、元数据或工具库文档，不一定需要执行工具。
- 共同机制：利用 Agent 的指令遵循和工具选择排序，让恶意工具进入合法候选或获得偏好。
- 主要失败：选择偏移、合法工具被用于未授权动作、工具生态公平性受损。
- 证据差异：A10 是大规模基准，A11 关注偏好与隐蔽性，A19 关注选择攻击和检测防御；摘要没有统一的工具库、模型和预算。
- 共同限制：即时选择结果多，持久偏好、工具描述写入记忆和跨 Agent 路由后果未形成统一基准。

### A4. 角色/格式/上下文信任混淆

- 代表论文：A14 ChatInject、A16 Role Confusion；也与 A02/A04 的间接注入相交。
- 攻击者入口：仿聊天模板、伪造 CoT、工具输出中的角色化文本。
- 共同机制：模型依据表达方式和上下文连贯性而非可信来源标签分配权重。
- 主要失败：把外部文本当用户或自身推理，随后改变规划或工具动作。
- 证据差异：A16 提供角色表征和首 token 预测的机制线索；A14 提供多轮 ASR 提升。两者都尚未证明角色表征变化必然导致长期状态改变。

### A5. 资源与效率操纵

- 代表论文：A13 CostBomb；A03/A20 的任务失败也可能带来资源成本，但摘要未作同一测量。
- 攻击者入口：网页中的诱导性长推理或重复任务提示。
- 主要机制和失败：在任务仍完成时增加推理、调用或计算成本。
- 限制：摘要未报告硬件、成本单位、预算上限和统计方法；必须在本地受限模拟中验证，不能接触真实服务或制造不可控负载。

## 攻击阶段和常见评价指标

| 阶段 | 典型论文 | 主要指标 | 可比性限制 |
|---|---|---|---|
| 感知/解析 | A03、A08、A15、A20 | 点击率、被欺骗率、受影响率 | 视觉页面、任务和动作空间不同 |
| 检索/选择 | A09、A10、A11、A17、A19 | ASR、选择率、拒绝率、隐蔽性 | 工具/搜索/证据的候选集合不同 |
| 规划/推理 | A02、A04、A06、A14、A16、A18 | ASR、迁移率、跨前缀鲁棒性 | 单轮、多轮、模板知识和输入顺序不同 |
| 动作/资源后果 | A01、A05、A13 | 外泄率、任务成功率、成本增幅 | 后果定义从 PII 到成本，不能单列成一个分数 |

## 共同防御和未覆盖设置

摘要中反复出现的防御包括系统/提醒式提示、忽略弹窗、广告提示、StruQ/SecAlign、DataSentinel、困惑度检测、视觉防御和人工监督。多个摘要报告这些防御有限，但没有统一的攻击预算和跨阶段对照。

本 corpus 中尚未被充分覆盖、但需要正文检索确认的设置是：外部内容被写入持久记忆后再影响规划；单一外部输入在多个 Agent 间传播；工具元数据偏好是否持久；外部真实片段是否能绕过“事实正确”过滤而改变全局信念。这里的“尚未充分覆盖”是对本次目标目录摘要的范围判断，不是整个文献领域的穷尽性结论。
