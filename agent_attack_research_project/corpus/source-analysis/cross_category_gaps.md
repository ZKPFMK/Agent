# 跨类别研究空白

## 证据和范围说明

以下结论基于本次目标目录中的 54 篇论文摘要清单，且明确排除了 A07/A21 的未知内容。措辞“本 corpus 未见统一验证”只表示在已扫描材料的摘要层面没有发现对应的完整对照，不代表整个领域不存在相关工作。正文逐页和外部文献检索尚未完成，因此每个空白都标为探索性判断。

## A × B：外部内容是否形成持久内部状态改变

- **共享攻击面**：A02/A05/A14 让网页或上下文内容改变即时规划；B10/B12/B13 让查询、图像或协作记录改变未来记忆和规划。
- **可连接前提**：外部内容只要被 Agent 的自动记忆摘要器保存，就可能成为后续检索样例；B04 已把环境观测作为后门触发入口，但摘要没有把环境注入和长期记忆持久性统一测量。
- **比较问题**：同一外部内容在“无记忆、单条显式记忆、自动摘要记忆”条件下的目标偏移和恢复速度是否不同？需要把 A 的即时 ASR 与 B 的持久性/检索率分开报告。
- **防御盲点**：A 的内容过滤可能在写入前有效，B 的记忆清理可能在写入后有效，但两者对自动生成的中性摘要是否有效未验证。
- **空白结论**：本 corpus 未见一个统一的、带记忆写入和重置反事实的 A×B 小型因果基准。[探索性推断；直接关联 A14、A05、B10、B12、B13]

## A × C：外部输入如何穿过编排和消息路由

- **共享攻击面**：A10/A19 作用于工具元数据和选择；A02/A04/A18 作用于外部文本和多源输入；C05/C13/C16 作用于通信、路由和消息组合；C10 说明外部恶意内容可劫持多 Agent 编排。
- **可连接前提**：编排器把外部内容包装成 Agent 消息，消息再被不同角色解释或转发；单 Agent 过滤通过不意味着组合后的消息安全。
- **比较问题**：把相同内容分别注入入口 Agent、路由消息和工具元数据，攻击成功差异来自内容、角色、路由还是多轮反馈？
- **防御盲点**：A 的输入检测、C 的消息监控和工具 allowlist 常各自独立；C16 的单组件良性/组合恶意提示了组合检测缺口。
- **空白结论**：本 corpus 未见统一控制“外部对象相同、路由位置不同”的实验矩阵。[探索性推断；直接关联 A10、A19、C10、C13、C16]

## B × C：记忆污染是否成为协作传播的稳定源

- **共享攻击面**：B03/B10/B13 改变记忆检索；C04/C07/C11/C19 研究跨 Agent 传播和 RAG 持久化；B02 也把多模态记忆作为传播起点。
- **可连接前提**：一个 Agent 的自动记忆写入可以把短期消息转成未来任务的高相似度样例，再经协作消息传播到其他 Agent。
- **比较问题**：传播依赖直接消息还是共享/独立记忆？清理源 Agent 后下游是否仍保持污染？拓扑、TTL 和检索阈值是否构成临界点？
- **防御盲点**：C 的标签/监督 Agent 监控通信，B 的记忆防御清理记录；两者联合对“良性内容生成的污染摘要”是否有效未验证。
- **空白结论**：本 corpus 未见在同一任务、同一模型和同一污染预算下同时报告记忆污染率、传播率、下游目标偏移与协作性能的对照。[探索性推断；直接关联 B10、B13、C11、C19]

## A × B × C：全链路状态—协作级联

- **已有链条证据**：A 的外部/视觉/工具入口见 A05、A14、A19；B 的记忆与规划见 B10、B12、B13；C 的多跳、汇聚和公开证据传播见 C04、C07、C18、C19。C18 已给出外部真实片段、受害信念和下游判定的组合，但其核心是信念操纵，并未统一测试持久记忆和工具后果。
- **可能的传播链**：外部内容 → 自动记忆摘要 → 规划/任务分解偏移 → 消息传播/路由 → 受控工具 canary 或最终任务结果。
- **关键未验证条件**：自动记忆器是否保存“事实片段”而非“攻击指令”；下游 Agent 是否把上游摘要当作独立证据；不同拓扑是否改变污染阈值；输入过滤和记忆清理的组合是否有盲区。
- **防御盲点**：逐阶段检测可能只看到局部正常输出；需要 provenance、因果一致性和跨 Agent 复核，而不是只看单条字符串。
- **空白结论**：这是最值得做但最容易被误判的交叉方向；若没有中间状态日志、置换/无记忆反事实和低权限对照，它只是已有攻击的串联，不能宣称新机制。[探索性假设；关联 A14、B13、C18、C19]

## 可比性和普适性风险

1. A 类常报告 ASR，B 类还报告投毒率、良性性能、检测率，C 类经常报告传播率、拓扑差异或隐蔽性；这些指标不能直接排序。
2. “单个 Agent 防御失败”不自动意味着“多 Agent 系统更脆弱”；需要固定模型、任务和攻击预算的单/多 Agent 配对对照。
3. “没有摘要中提到防御”不等于没有防御；本清单将这类信息写成未验证。
4. A07/A21 的缺摘要材料可能改变 A 类分类分布，因此任何“空白”都需在 PDF 可读后复核。
