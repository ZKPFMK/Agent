## ACL-oriented paper bar

The project should present an Agent Attack contribution as an NLP/LLM research problem:

- the attack mechanism must depend on language, agent instruction following, communication, memory or reasoning;
- tasks, prompts, messages, evidence and model behavior must be specified clearly enough for NLP reviewers to audit;
- related work must cover ACL/EMNLP/NAACL/Findings as well as security and agent venues;
- evaluation must include strong language-model baselines, exact or human-validated evaluators, ablations,
  cross-model checks, benign utility and failure analysis;
- the paper must distinguish a benchmark/evaluation contribution from a new attack mechanism;
- artifact, ethics, anonymization, data and reproducibility requirements from the current ACL/ARR call must be
  checked before submission.

The official call and ARR instructions are the authority for page limits, review model, anonymity, commitment,
formatting, ethics and artifact rules. Recheck them immediately before the R0 gate is closed and again before ARR
submission.
