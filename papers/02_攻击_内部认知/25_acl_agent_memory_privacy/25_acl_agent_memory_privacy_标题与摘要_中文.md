# 揭示大语言模型智能体记忆中的隐私风险

**原标题：**Unveiling Privacy Risks in LLM Agent Memory  
**攻击方法：**Memory EXTRaction Attack（MEXTRA，记忆提取攻击）  
**年份与会议：**2025，ACL（第 63 届年会，长论文）。  
**原文：**[本地 PDF](./25_acl_agent_memory_privacy.pdf)。

## 摘要

大语言模型（large language model，LLM）智能体正越来越多地应用于各种现实世界场景。为了提升决策能力，智能体会将用户与智能体之间的私密交互存储在记忆模块中，以便作为示例使用，这也为 LLM 智能体引入了新的隐私风险。

本文在黑盒场景下系统研究了 LLM 智能体对我们提出的记忆提取攻击（Memory EXTRaction Attack，MEXTRA）的脆弱性。为从记忆中提取私人信息，我们设计了有效的攻击提示词，并根据攻击者对 LLM 智能体掌握的不同程度知识，提出了一种自动化提示词生成方法。

在两个具有代表性的智能体上开展的实验表明，MEXTRA 十分有效。此外，我们从智能体设计者和攻击者两个角度，探讨了影响记忆泄露的关键因素。我们的研究结果凸显了在 LLM 智能体设计与部署过程中建立有效记忆安全防护的迫切需求。
