# MemIncept：通过协作式隐蔽记忆注入引导大语言模型智能体

**原标题：**MemIncept: Steering LLM Agents via Cooperative Stealthy Memory Injections  
**攻击方法：**MemIncept（协作式隐蔽记忆注入）  
**年份与会议：**2026，ICML。  
**原文：**[本地 PDF](./26_icml_memincept.pdf)。

## 摘要

长期记忆赋予基于大语言模型（large language model，LLM）的智能体自适应推理能力，但也暴露出一个关键攻击面：攻击者可以注入恶意记录，使智能体的行为产生偏移。然而，现有攻击面临两难：有效的注入通常带有明显的恶意性，容易被检测；隐蔽且看似良性的注入往往又难以有效改变智能体行为。

为解决这一问题，我们提出 MemIncept，一种记忆投毒攻击。即使在黑盒场景下，攻击者只使用看似良性的查询，也能对智能体产生影响。不同于以往注入孤立记录的方法，MemIncept 生成一组相互协作的查询，共同引导智能体的行为。该方法通过双向进化策略从两端优化查询集合：正向过程确保这些查询共同将智能体引向目标结果；反向过程确保它们在语义上接近受害者的良性查询，以便可靠地被检索出来。

这种“会师于中间”（meet-in-the-middle）的方法生成的注入记录既容易被检索，又能有效引导智能体行为。通过在多种智能体上开展大量实验，我们表明，MemIncept 显著优于单记录攻击，在保持难以被自动化过滤器或人工检查发现的同时，取得了接近显式攻击的高成功率。
