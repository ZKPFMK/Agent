# Breaking Agents：通过故障放大破坏自主大语言模型智能体

**原标题：**Breaking Agents: Compromising Autonomous LLM Agents Through Malfunction Amplification  
**攻击方法：**Malfunction Amplification（故障放大攻击）  
**年份与会议：**2025，EMNLP。  
**原文：**[本地 PDF](./25_emnlp_breaking_agents.pdf)。

## 摘要

近年来，基于大语言模型（large language models，LLM）构建的自主智能体取得了显著发展，并开始部署在现实世界的应用中。这些系统能够借助工具执行现实世界中的操作。鉴于智能体的实际应用及其执行重要操作的能力，一旦遭到破坏，这类自主系统可能造成比独立运行的大语言模型更严重的损害。

尽管已有研究探索了 LLM 智能体执行有害操作的风险，本文从不同角度研究这一脆弱性。我们提出了一类新的攻击，通过误导智能体执行重复或无关的操作来引发故障。实验表明，在多种场景中，这类攻击能够使智能体的失败率超过 80%。

通过在多智能体场景中攻击已经实现且可部署的智能体，我们进一步凸显了这些漏洞所带来的现实风险。为缓解此类攻击，我们提出了自我检查防御方法。研究结果表明，与此前公开的明显有害攻击相比，这类攻击更加难以检测，凸显了该类漏洞所带来的重大风险。
