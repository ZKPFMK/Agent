# UDora：通过动态劫持自身推理实现对大语言模型智能体的统一红队测试

**原标题：**UDora: A Unified Red Teaming Framework against LLM Agents by Dynamically Hijacking Their Own Reasoning  
**攻击方法：**UDora  
**年份与会议：**2025，ICML。  
**原文：**[本地 PDF](./25_icml_udora.pdf)。

## 摘要

配备外部工具的大语言模型（large language model，LLM）智能体在网页购物、自动回复电子邮件和金融交易等复杂任务中变得越来越强大。然而，随着智能体能够访问敏感的外部功能，对抗性攻击带来的风险也随之加剧。尽管如此，要操纵 LLM 智能体执行指定的恶意操作或调用特定工具仍然十分困难，因为这类智能体通常会在执行最终动作前进行大量推理或规划。

本文提出 UDora，一个面向 LLM 智能体的统一红队测试框架，通过动态劫持智能体的推理过程，迫使其产生恶意行为。具体而言，UDora 首先针对给定任务生成模型的推理轨迹，然后自动识别该轨迹中适合插入定向扰动的最佳位置。随后，使用经过扰动的推理作为替代响应进行优化。通过反复执行这一过程，可以诱导 LLM 智能体执行指定的恶意操作或调用特定的恶意工具。

在三个 LLM 智能体数据集上的实验表明，与现有方法相比，我们的方法具有更强的有效性。
