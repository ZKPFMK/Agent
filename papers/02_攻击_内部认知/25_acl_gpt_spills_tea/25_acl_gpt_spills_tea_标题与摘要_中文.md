# 当 GPT 泄露内幕：GPT 知识文件泄露的全面评估

**原标题：**When GPT Spills the Tea: Comprehensive Assessment of Knowledge File Leakage in GPTs  
**攻击类型：**知识文件泄露（Knowledge File Leakage）  
**年份与会议：**2025，ACL（第 63 届年会，长论文）。  
**原文：**[本地 PDF](./25_acl_gpt_spills_tea.pdf)。

## 摘要

知识文件已广泛用于 GPT 等大语言模型（large language model，LLM）智能体，以提升响应质量。然而，人们对知识文件可能泄露的担忧也日益加剧。已有研究表明，对抗性提示词能够诱导 GPT 泄露知识文件内容。但鉴于 GPT 中客户端、服务器和数据库之间存在复杂的数据流，目前仍不清楚是否还存在其他泄露向量。

本文借鉴数据安全态势管理（Data Security Posture Management，DSPM）的思想，提出了一套新型工作流，对知识文件泄露风险进行了全面评估。通过分析 651,022 条 GPT 元数据、11,820 条数据流和 1,466 条响应，我们识别出五种泄露向量：元数据、GPT 初始化、检索、沙箱执行环境和提示词。

这些泄露向量使攻击者能够提取知识文件中的敏感数据，例如标题、内容、类型和大小。值得注意的是，启用内置工具 Code Interpreter 会导致权限提升漏洞，使攻击者能够直接下载原始知识文件，成功率达到 95.95%。进一步分析发现，泄露文件中有 28.80% 受版权保护，其中包括主要出版商的数字副本和某家上市公司的内部材料。

最后，我们为 GPT 构建者和平台提供商提出了可操作的解决方案，以保护 GPT 数据供应链的安全。
