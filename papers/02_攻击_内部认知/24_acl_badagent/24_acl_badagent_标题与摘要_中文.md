# BadAgent：在大语言模型智能体中植入并激活后门攻击

**原标题：**BadAgent: Inserting and Activating Backdoor Attacks in LLM Agents  
**攻击方法：**BadAgent  
**年份与会议：**2024，ACL（第 62 届年会，长论文）。  
**原文：**[本地 PDF](./24_acl_badagent.pdf)。

## 摘要

随着大语言模型（large language models，LLM）的蓬勃发展，研究者已经构建了功能强大的基于 LLM 的智能体，通过一组用户定义的工具提供定制化服务。当前最先进的 LLM 智能体构建方法通常以训练好的 LLM 为基础，再利用智能体任务数据对其进行微调。然而，我们发现，这类方法在多种智能体任务上容易受到我们提出的后门攻击 BadAgent 的影响：攻击者可以通过在后门数据上进行微调，将后门植入模型。

在测试阶段，攻击者只需在智能体输入或环境中呈现触发器，就可以操纵已部署的 LLM 智能体执行有害操作。出乎意料的是，即使之后使用可信数据进行微调，我们提出的攻击方法仍然具有极强的鲁棒性。

尽管后门攻击已经在自然语言处理领域得到广泛研究，但据我们所知，我们可能是首个研究 LLM 智能体后门攻击的工作。由于 LLM 智能体拥有使用外部工具的权限，这类攻击更加危险。我们的工作揭示了基于不可信 LLM 或不可信数据构建 LLM 智能体所带来的明确风险。
