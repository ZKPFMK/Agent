# 通过仅查询交互对大语言模型智能体实施记忆注入攻击

**原标题：**Memory Injection Attacks on LLM Agents via Query-Only Interaction  
**攻击方法：**Memory INJection Attack（MINJA，记忆注入攻击）  
**年份与会议：**2025，NeurIPS。  
**原文：**[本地 PDF](./25_neurips_memory_injection.pdf)。

## 摘要

由大语言模型（large language models，LLM）驱动的智能体已经在广泛的复杂现实应用中展现出强大能力。然而，如果智能体的记忆库遭到破坏，当智能体检索到恶意历史记录作为示例时，就很容易生成有害输出。

本文提出一种新的记忆注入攻击（Memory INJection Attack，MINJA），不要求攻击者能够直接修改智能体的记忆库。攻击者只需通过查询和观察输出与智能体交互，就能将恶意记录注入记忆库。这些恶意记录经过专门设计，能够在智能体执行受害用户查询时，诱发一系列与另一目标查询相对应的恶意推理步骤。

具体而言，我们引入一系列桥接步骤，将受害查询连接到恶意推理步骤。在记忆注入过程中，我们提出一种指示提示词，引导智能体自主生成相似的桥接步骤，并采用渐进缩短策略逐步移除指示提示词，使恶意记录在之后处理受害查询时能够更容易被检索出来。

在多种智能体上的大量实验表明，MINJA 能够有效破坏智能体记忆。在执行要求极低的情况下，MINJA 使任意用户都能够影响智能体记忆，揭示了这一攻击带来的风险。
