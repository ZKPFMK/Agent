# AgentPoison：通过投毒记忆或知识库对大语言模型智能体进行红队测试

**原标题：**AGENTPOISON: Red-teaming LLM Agents via Poisoning Memory or Knowledge Bases  
**攻击方法：**AgentPoison  
**年份与发布形式：**2024，arXiv 预印本。  
**原文：**[本地 PDF](./24_neurips_agentpoison.pdf)。

## 摘要

大语言模型智能体凭借先进的推理能力、利用外部知识和工具的能力、调用 API 的能力，以及与环境交互并执行操作的能力，在各种应用中展现出卓越性能。当前智能体通常使用记忆模块或检索增强生成（retrieval-augmented generation，RAG）机制，从知识库中检索过去的知识和具有相似嵌入的实例，为任务规划与执行提供信息。然而，依赖未经验证的知识库也引发了对智能体安全性和可信性的重大担忧。

为揭示这些漏洞，我们提出了一种新的红队测试方法 AgentPoison。这是首个针对通用型和基于 RAG 的大语言模型智能体、通过投毒其长期记忆或 RAG 知识库实施的后门攻击。具体而言，我们将触发器生成过程建模为一个约束优化问题：通过将带触发器的实例映射到独特的嵌入空间来优化后门触发器，从而确保只要用户指令包含经过优化的后门触发器，就能以较高概率从遭到投毒的记忆或知识库中检索出恶意示例。同时，不含触发器的良性指令仍能保持正常性能。

与传统后门攻击不同，AgentPoison 无需额外的模型训练或微调；其优化得到的后门触发器还表现出更强的迁移能力、上下文内连贯性和隐蔽性。

大量实验表明，AgentPoison 能够有效攻击三类现实世界的大语言模型智能体：基于 RAG 的自动驾驶智能体、知识密集型问答智能体和医疗 EHRAgent。我们分别将投毒实例注入这些智能体的 RAG 知识库和长期记忆，证明了 AgentPoison 的泛化能力。在每种智能体上，AgentPoison 的平均攻击成功率均达到 80% 以上，同时对良性性能的影响不超过 1%，且投毒率低于 0.1%。
