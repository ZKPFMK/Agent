# Ethics and Containment

## Allowed targets

- 本地实现；
- 项目自有 sandbox；
- 明确授权的 benchmark；
- 合成 MCP server、合成工具和合成敏感数据。

## Prohibited targets

- 真实第三方 MCP server；
- 公开 registry 的攻击性测试；
- 生产环境；
- 真实用户、账号、凭据或私有数据；
- 未经授权的云 API 或网站。

## Release rules

- 不提交真实攻击 payload；
- 不提交凭据、个人信息或私有论文；
- 记录攻击能力、危害和缓解措施；
- 真实漏洞需要先走负责任披露；
- 发布 artifact 前重新审查可滥用性。
