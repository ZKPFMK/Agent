# ChatInject：滥用聊天模板对大语言模型智能体实施提示词注入

**原标题：**CHATINJECT: ABUSING CHAT TEMPLATES FOR PROMPT INJECTION IN LLM AGENTS  
**攻击方法：**ChatInject  
**年份与会议：**2026，ICLR。  
**原文：**[本地 PDF](./26_iclr_chatinject.pdf)。

## 摘要

随着与外部环境交互的大语言模型智能体得到日益广泛的部署，对抗性操纵也有了新的攻击面。其中一项主要威胁是间接提示词注入（indirect prompt injection）：攻击者在外部环境的输出中嵌入恶意指令，使智能体将其视为合法提示词并加以理解和执行。以往研究主要关注纯文本注入攻击，而我们发现了一类重要但尚未得到充分研究的漏洞：大语言模型依赖结构化聊天模板（chat templates），并且容易在具有说服性的多轮对话中受到上下文操纵。

为此，我们提出 ChatInject，通过将恶意载荷组织成模仿原生聊天模板的格式，利用模型固有的指令遵循倾向。在此基础上，我们进一步开发了一种基于模板的多轮（Multi-turn）攻击变体，在多个对话轮次中逐步引导智能体，使其接受并执行原本可疑的操作。

通过针对前沿大语言模型开展全面实验，我们得出三项关键发现：（1）ChatInject 的平均攻击成功率显著高于传统提示词注入方法，在 AgentDojo 上从 5.18% 提升至 32.05%，在 InjecAgent 上从 15.13% 提升至 45.90%；其中，多轮对话的表现尤为突出，在 InjecAgent 上的平均攻击成功率达到 52.33%。（2）基于聊天模板的攻击载荷具有较强的跨模型迁移能力；即使闭源大语言模型的模板结构未知，这些载荷仍然有效。（3）现有基于提示词的防御方法在很大程度上无法有效抵御此类攻击，尤其难以应对多轮攻击变体。这些发现揭示了当前智能体系统中的漏洞。
