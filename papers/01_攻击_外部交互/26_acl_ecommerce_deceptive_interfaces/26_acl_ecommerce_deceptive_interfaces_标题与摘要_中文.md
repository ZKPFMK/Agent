# 欺骗性电子商务界面下的网页智能体安全性评测

**原标题：**Benchmarking Web Agent Safety under E-commerce Deceptive Interfaces  
**评测框架：**WebDecept  
**年份与会议：**2026，ACL（第 64 届年会，长论文）。  
**原文：**[本地 PDF](./26_acl_ecommerce_deceptive_interfaces.pdf)。

## 摘要

随着自主网页智能体越来越多地被部署来执行现实世界中的任务，确保其安全性已成为一个关键问题。本文研究了电子商务领域中，网页智能体在真实欺骗性界面下的行为。我们提出 WebDecept，这是一个轻量且可配置的插件框架，能够将受控的欺骗性界面模式注入现有网页环境。

借助 WebDecept，我们实例化了开放网络中常见的七种欺骗性模式，包括定向广告、域名重定向和购物操纵。我们在任务执行过程中将这些模式注入网页前端，从而对多个多模态网页智能体开展受控评测。

结果表明，当前网页智能体很容易受到多类欺骗性界面的影响，而基于提示词的约束通常不足以缓解这些失败。我们进一步分析了欺骗性模式的设计选择如何影响这类操纵的成功率。这些发现揭示了网页智能体向现实世界扩展部署时需要解决的安全挑战。
