# WIPI：面向大语言模型驱动网页智能体的新型网络威胁

**原标题：**WIPI: A New Web Threat for LLM-Driven Web Agents  
**攻击方法：**Web Indirect Prompt Injection（WIPI，网页间接提示词注入）  
**年份与发布形式：**2024，arXiv 预印本。  
**原文：**[本地 PDF](./24_arxiv(preprint)_wipi.pdf)。

## 摘要

随着大语言模型（large language models，LLM）快速发展，大语言模型驱动的网页智能体（以下简称网页智能体）凭借强大的能力受到广泛关注：LLM 作为类似人类大脑的决策核心，配备多个网页工具，能够主动与外部部署的网站交互。随着大量网页智能体不断发布，这类 LLM 系统快速发展并逐渐走向日常生活中的广泛部署，一个关键且紧迫的问题随之出现：“这些网页智能体安全吗？”

本文提出了一种新型威胁 WIPI，即网页间接提示词注入（Web Indirect Prompt Injection）。该攻击利用公开可访问网页中嵌入的恶意指令，间接控制网页智能体执行攻击者指定的操作。为了使 WIPI 攻击能够在黑盒环境中成功实施，我们设计了一套方法，重点优化外部网页中间接指令的形式和内容，从而提高攻击的效率与隐蔽性。

为评估所提方法的有效性，我们使用 7 个基于插件的 ChatGPT 网页智能体、8 个 Web GPT 以及 3 个不同的开源网页智能体开展了大量实验。结果表明，即使在纯黑盒场景下，该方法的平均攻击成功率（attack success rate，ASR）仍超过 90%。此外，通过针对不同用户前缀指令开展消融实验，我们证明 WIPI 具有较强的鲁棒性，能够在多种前缀指令下保持较高的攻击效果。
