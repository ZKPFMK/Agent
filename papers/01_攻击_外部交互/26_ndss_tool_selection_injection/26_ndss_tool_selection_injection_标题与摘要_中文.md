# 针对大语言模型智能体工具选择的提示词注入攻击

**原标题：**Prompt Injection Attack to Tool Selection in LLM Agents  
**攻击方法：**ToolHijacker  
**年份与会议：**2026，NDSS。  
**原文：**[本地 PDF](./26_ndss_tool_selection_injection.pdf)。

## 摘要

工具选择是大语言模型智能体的关键组成部分。一种常见的方法采用“检索—选择”两步流程，从工具库中为给定任务挑选最合适的工具。在本文中，我们提出 ToolHijacker，一种在无盒（no-box）场景下针对工具选择的新型提示词注入攻击。ToolHijacker 向工具库中注入恶意工具文档，操纵大语言模型智能体的工具选择过程，使其在执行攻击者选定的目标任务时，持续选择攻击者的恶意工具。

具体而言，我们将此类工具文档的构造建模为一个优化问题，并提出两阶段优化策略来求解。广泛的实验评估表明，ToolHijacker 具有很强的攻击效果，在针对工具选择的攻击中，显著优于现有的人工构造和自动化提示词注入方法。

此外，我们考察了多种防御方法，包括预防型防御（StruQ 和 SecAlign）以及检测型防御（已知答案检测、DataSentinel、困惑度检测和滑动窗口困惑度检测）。实验结果表明，这些防御方法仍不足以有效抵御该攻击，凸显了开发新防御策略的迫切需求。
