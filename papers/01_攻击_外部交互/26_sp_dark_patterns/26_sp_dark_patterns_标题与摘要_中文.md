# 研究暗黑模式对基于大语言模型的网页智能体的影响

**原标题：**Investigating the Impact of Dark Patterns on LLM-Based Web Agents  
**评测框架：**LiteAgent、TrickyArena  
**年份与会议：**2026，IEEE Symposium on Security and Privacy。  
**原文：**[本地 PDF](./26_sp_dark_patterns.pdf)。

## 摘要

随着用户越来越多地使用基于大语言模型（large language model，LLM）的网页智能体来自动完成在线任务，智能体可能会遇到暗黑模式（dark patterns）：操纵用户做出非预期决定的欺骗性用户界面设计。尽管暗黑模式主要针对人类用户，但其对基于 LLM 的通用网页智能体可能造成的有害影响仍未得到研究。

本文首次系统研究了暗黑模式对基于 LLM 的通用网页智能体决策过程的影响。为此，我们提出 LiteAgent，一个轻量级框架，能够自动提示智能体执行任务，同时记录交互的完整日志和屏幕录像。我们还提出 TrickyArena，这是一个受控环境，包含来自电子商务、流媒体服务和新闻平台等领域的网页应用；每个应用都包含多种真实且多样的暗黑模式，并且可以选择启用或禁用。

我们利用 LiteAgent 和 TrickyArena 开展了多项实验，评估单个暗黑模式及其组合对网页智能体行为的影响。我们在三种大语言模型上评测了六个流行的基于 LLM 的通用网页智能体，发现当存在单个暗黑模式时，智能体平均有 41% 的概率受到其影响。我们还发现，通过视觉设计变化或 HTML 代码调整来修改暗黑模式的界面属性，以及同时引入多个暗黑模式，都会影响智能体对暗黑模式的易感性。

本研究强调，网页智能体需要整体性的防御机制，同时涵盖针对智能体的专项防护和更广泛的网页安全措施。
