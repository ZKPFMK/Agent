# 多智能体安全税：多智能体系统中的安全性与协作能力权衡

**原标题：**Multi-Agent Security Tax: Trading Off Security and Collaboration Capabilities in Multi-Agent Systems  
**攻击方式：**感染式恶意提示词（infectious malicious prompts）  
**年份与会议：**2025，AAAI。  
**原文：**[本地 PDF](./25_aaai_multiagent_security_tax.pdf)。

## 摘要

随着 AI 智能体越来越多地被用于协作完成复杂目标，确保自主多智能体系统的安全性变得至关重要。我们构建了智能体围绕共同目标进行协作的模拟环境，以研究这类安全风险及其权衡关系。

我们重点研究这样一种场景：攻击者攻破一个智能体，利用它污染其他智能体，进而引导整个系统朝着偏离目标的结果发展。在这一背景下，我们观察到了感染式恶意提示词，即恶意指令通过多跳通信在智能体之间传播。

为缓解这一风险，我们评估了多种策略：两种“疫苗接种”方法，即向智能体的记忆流中插入其安全处理恶意输入的虚假记忆；以及两个版本的通用安全指令策略。实验表明，这些防御能够减少恶意指令的传播和执行，但往往会削弱智能体网络的协作能力。

我们的研究展示了多智能体系统中安全性与协作效率之间潜在的权衡关系，并为设计更加安全且有效的多智能体协作提供了参考。
