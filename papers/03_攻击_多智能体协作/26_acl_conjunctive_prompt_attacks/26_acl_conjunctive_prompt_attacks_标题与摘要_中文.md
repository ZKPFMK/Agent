# 多智能体大语言模型系统中的合取式提示词攻击

**原标题：**Conjunctive Prompt Attacks in Multi-Agent LLM Systems  
**攻击方法：**Conjunctive Prompt Attack（合取式提示词攻击）  
**年份与会议：**2026，ACL（第 64 届年会，长论文）。  
**原文：**[本地 PDF](./26_acl_conjunctive_prompt_attacks.pdf)。

## 摘要

大多数大语言模型安全研究关注单智能体模型，但许多现实应用依赖多个相互交互的智能体。在这类系统中，提示词分段和智能体间路由形成了单智能体评测无法覆盖的攻击面。

我们研究合取式提示词攻击：用户查询中的触发键与某个遭到破坏的远程智能体中的隐藏对抗模板，单独看都表现为良性，但当路由将二者结合时，就会激活有害行为。我们考虑一种攻击者模型：既不修改模型权重，也不修改客户端智能体，只控制触发器的放置和模板的插入。

在星形、链式和有向无环图（DAG）拓扑上，考虑路由的优化显著提升了攻击成功率，同时保持较低的误激活率。现有防御（包括 PromptGuard、Llama-Guard 各种变体，以及工具限制等系统级控制）无法可靠阻止该攻击，因为单个组件孤立来看都没有表现出恶意性。

这些结果揭示了智能体 LLM 流程中的结构性漏洞，并促使人们开发能够从路由和跨智能体组合角度进行推理的防御方法。
