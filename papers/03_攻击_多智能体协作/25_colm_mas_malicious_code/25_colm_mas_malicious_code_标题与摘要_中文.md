# 多智能体系统执行任意恶意代码

**原标题：**Multi-Agent Systems Execute Arbitrary Malicious Code  
**攻击方式：**恶意内容劫持多智能体系统的控制与通信  
**年份与会议：**2025，COLM。  
**原文：**[本地 PDF](./25_colm_mas_malicious_code.pdf)。

## 摘要

多智能体系统协调基于大语言模型的智能体，代表用户执行任务。在现实应用中，多智能体系统不可避免地会与不可信输入交互，例如恶意网页内容、文件、电子邮件附件等。

我们以近期提出的多个多智能体框架为具体实例，证明对抗性内容能够劫持系统内部的控制流和通信流，调用不安全的智能体与功能。这会导致完整的安全破坏，甚至可能在用户设备上执行任意恶意代码，或从用户的容器化环境中窃取敏感数据。

例如，当智能体使用 GPT-4o 实例化时，基于网页的攻击能够在 58%—90% 的试验中成功使多智能体系统执行任意恶意代码，具体比例取决于编排器。在某些模型与编排器配置下，攻击成功率达到 100%。

我们还证明，即使单个智能体不容易受到直接或间接提示词注入攻击，即使它们拒绝执行有害操作，这些攻击仍然能够成功。我们希望这些结果能够推动在多智能体系统大规模部署之前，建立相应的信任模型和安全模型。
