# 追踪 MCP 安全漏洞：MCP 安全漏洞数据集的构建与分析

**原标题：**Tracing MCP Security Vulnerabilities: Constructing and Analyzing an MCP Security Vulnerability Dataset  
**年份与会议：**2026，IEEE Symposium on Security and Privacy Workshops（SPW）。  
**原文：**[本地 PDF](./26_arxiv_tracing_mcp_security_vulnerabilities_dataset.pdf)。  
**数据集：**<https://huggingface.co/datasets/XuViewer/mcp-vulnerability-dataset>

## 摘要

模型上下文协议（Model Context Protocol，MCP）作为连接大语言模型（LLM）与外部数据源和工具的核心协议，已经迅速成为新兴 AI 智能体系统中的关键接口。随着 MCP 生态系统不断扩张，报告的漏洞数量也在增加，形成了日益扩大的软件安全攻击面。然而，MCP 漏洞信息仍然分散、噪声较多，难以进行系统研究。本文针对这一缺口，基于 CVE 披露信息构建了一个经过整理的 MCP 漏洞数据集。我们从截至 2026 年 2 月检索到的 119 条 MCP 相关记录出发，过滤掉无关案例，最终得到一个包含 24 个经过验证的 MCP 漏洞的快照。我们的过滤方法明确处理了“MCP”这一缩写的歧义；在抽样的排除记录审计中，研究人员之间的一致率达到 96.7%，同时保留了公开安全公告中已知的所有高严重性 MCP 案例。在这一初始数据集快照中，87.5% 的已验证漏洞被评为严重（Critical）或高危（High），注入漏洞和路径遍历漏洞合计占 66.7%。我们还发现了一些反复出现的问题，包括输入验证不足、访问控制不当以及协议层安全缺口。通过对 6 个具有代表性的案例进行研究，我们展示了常见的利用模式，并将其对应到实际可行的防御措施。我们发布该数据集、可复现工具以及可持续的维护工作流，为未来的 MCP 安全度量、基准测试和防御研究提供基础。

**关键词：**模型上下文协议（MCP）；CVE 漏洞数据集；AI 智能体安全

## 1 引言

模型上下文协议（Model Context Protocol，MCP）已经成为现代 AI 智能体系统的基础组成部分（Anthropic，2024）。MCP 为大语言模型（LLM）与文件系统、数据库和 API 等外部资源交互提供了标准化方式。因此，一个以 MCP 为中心的 AI 工具生态系统已经形成，其中包括 AI 驱动的编程助手（例如 Claude（Anthropic，2024）和 Cursor（Anysphere，2023））、智能体（Wang 等，2025）以及企业级 AI 系统（Yang 等，2025）。然而，这一不断扩大的生态系统也带来了安全问题。MCP 实现中的漏洞可能导致未经授权的数据访问、远程代码执行以及系统失陷（Li 等，2025）。尽管 MCP 的攻击面不断扩大，研究社区仍面临一个根本性挑战：缺乏高质量、经过整理的数据集来开展系统性安全分析。这一缺口阻碍了研究人员理解漏洞模式、开发检测工具和实施有效防御。

系统性的 MCP 安全数据集之所以稀缺，有几个原因。MCP 于 2024 年 12 月首次发布（Anthropic，2024）。在这段较短的时间内，社区主要关注 MCP 的能力和使用场景，而不是其安全影响。新闻报道和技术报告（Hou 等，2025；Guo 等，2025）偶尔会指出利用 MCP 攻陷基于 LLM 的应用的攻击，但现有讨论主要集中于提示词注入和恶意工具编排等 AI 层风险，而不是 MCP 实现自身的软件层漏洞。因此，目前还不存在经过整理的 MCP 漏洞数据集。

我们观察到，近几个月来与 MCP 相关的 CVE 数量不断累积，因此将其作为开展系统研究的机会。我们收集并分析这些 CVE，构建了一个经过整理的 MCP 漏洞数据集。由于“MCP”这一缩写也被用于芯片互连、Linux 内核驱动等无关领域，我们采用过滤流程，验证每条记录是否确实与 AI 语境下的 MCP 相关。最终发布的数据集包含截至 2026 年 2 月披露的 24 个经过验证的 MCP 漏洞的冻结快照。

随后，我们分析收集到的 CVE，并对具有代表性的案例开展研究。在这一初始快照中，87.5% 的已验证漏洞被评为严重或高危。最常见的漏洞类型是命令注入、远程代码执行和路径遍历，三者合计占大多数案例。这些观察表明，当前 MCP 实现经常在输入验证、访问控制，或两者方面存在缺陷。通过研究 6 个高严重性漏洞案例，我们进一步分析其利用路径，并识别出反复出现的攻击模式，包括对工具参数清理不足，以及服务器配置权限过宽。本文并不声称构建了一个全面的基准；相反，我们利用这些发现提出有针对性的防御建议，并展示该数据集如何支持未来的自动化安全审计研究。

本文的主要贡献如下：

- **构建经过整理的 MCP CVE 数据集。**我们构建了一个包含 24 个经过验证漏洞的 MCP CVE 数据集，并发布截至 2026 年 2 月的冻结快照，以及用于验证、规范化、丰富数据和审计数据漂移的工具。
- **开展多维度实证分析。**我们从严重性等级、漏洞类型、受影响组件和时间模式等维度，对当前漏洞披露快照进行了实证分析，提供了关于反复出现的安全问题及其可能根因的初步证据。
- **研究代表性高严重性漏洞。**我们对 6 个具有代表性的高严重性漏洞开展深入案例研究，识别常见的利用模式，并提出可执行的防御建议。
