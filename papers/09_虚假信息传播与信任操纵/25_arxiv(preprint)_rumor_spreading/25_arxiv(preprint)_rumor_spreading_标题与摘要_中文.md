# 使用 LLM Agent 模拟社交网络中的谣言传播

**原标题：**Simulating Rumor Spreading in Social Networks using LLM Agents  
**作者：**Tianrui Hu；Dimitrios Liakopoulos；Xiwen Wei；Radu Marculescu；Neeraja J. Yadwadkar  
**年份与会议/期刊：**2025，arXiv 预印本  
**本地 PDF：**[本地 PDF](./25_arxiv(preprint)_rumor_spreading.pdf)  
**原文链接：**<https://arxiv.org/abs/2502.01450>  
**版本说明：**使用 arXiv 公开预印本版本。  

## 摘要或内容概述

本文利用多类 LLM Agent 和多种社会网络结构模拟谣言传播过程。实验覆盖超过 100 个 Agent 和数千条网络边，分析网络拓扑、Agent 人格以及传播规则对扩散范围和速度的影响。结果表明，不同网络结构与 Agent 异质性会显著改变谣言传播，部分设置下影响范围可达到约 83% 的 Agent。

## 研究问题

网络拓扑、Agent persona 和传播规则如何改变大规模 LLM Agent 社会中的谣言扩散？

## 方法

设计多种 LLM Agent 类型和四种网络结构，在超过 100 个 Agent、数千条边的模拟网络中运行谣言传播实验。

## 主要发现

小世界网络和高连接节点更容易形成广泛扩散；Agent 人格与传播机制会改变速度、覆盖率和最终规模。

## 研究意义

提供可扩展的宏观谣言传播模拟基线，便于和恶意注入、纠正及治理策略比较。
