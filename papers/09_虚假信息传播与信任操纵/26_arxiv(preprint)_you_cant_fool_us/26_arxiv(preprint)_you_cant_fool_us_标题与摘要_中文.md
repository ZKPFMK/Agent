# 你骗不了我们：理解 LLM 驱动 Agent 社区对错误信息的韧性

**原标题：**You Can't Fool Us: Understanding the Resilience of LLM-driven Agent Communities to Misinformation  
**作者：**Chichen Lin；Yijie Jin；Kangbo Hu；Weijian Fan；Han Xiao；Yongbin Wang；Zhihui Ying；Zhanzhan Zhao  
**年份与会议/期刊：**2026，arXiv 预印本  
**本地 PDF：**[本地 PDF](./26_arxiv(preprint)_you_cant_fool_us.pdf)  
**原文链接：**<https://arxiv.org/abs/2605.17353>  
**版本说明：**使用 arXiv 公开预印本版本。  

## 摘要或内容概述

本文研究 LLM 驱动的 Agent 社区如何抵抗和恢复错误信息。作者以主动开放思维（AOT）和政治意识形态（PI）构造异质社区，观察信念采纳、证据搜寻、纠正和支持撤回。结果表明，开放思维有助于抵抗错误信息并促进恢复，而群体结构和意识形态会影响错误信念的纠正路径。

## 研究问题

社区的开放思维、政治意识形态和结构如何影响错误信息的初始采纳与后续恢复？

## 方法

沿 AOT 与 PI 两个维度生成异质 LLM Agent 社区，施加可信错误信息冲击，测量采纳、质疑、纠正和支持撤回的动态过程。

## 主要发现

高开放思维 Agent 更愿意寻找证据并修正信念；意识形态相似度和社区结构会改变错误信息的持续时间与恢复路径。

## 研究意义

从防御和恢复角度补充传播攻击研究，为群体韧性评测提供 Agent 特征维度。
