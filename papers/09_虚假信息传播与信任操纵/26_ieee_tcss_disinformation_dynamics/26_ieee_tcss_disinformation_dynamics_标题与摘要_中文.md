## 摘要或内容概述

本文提出一个由 LLM 驱动的多智能体社会模拟模型，用于研究认知异质性、网络拓扑、消息框架和官方干预如何共同影响虚假信息传播动力学。模型将 Agent 的认知特征与社会网络交互结合，比较不同传播和治理条件下的信息扩散结果。

## 研究问题

认知异质性、网络拓扑、消息叙事框架和官方干预如何共同改变虚假信息传播动力学？

## 方法

将认知特征化的 LLM Agent 放入社会网络，改变激进 Agent 比例、拓扑、消息框架和干预时机，比较传播强度和控制效果。

## 主要发现

激进 Agent 比例更高、消息叙事性更强时传播更强；及时、针对性的官方干预可以明显抑制扩散。

## 研究意义

为传播网络、认知差异和治理策略的组合研究提供宏观模拟模型。
